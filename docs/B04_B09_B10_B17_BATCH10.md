Existing status values are preserved. Date-shift is stored as dataset metadata, not altered timestamps.

## Important outstanding acceptance work
- **B04:** fresh empty DB bootstrap and full schema migration reproducibility not proven solely by this batch. Compare clean baseline and migrated DB under isolated DB CI.
- **B09:** source-unit assertions need verification with data owner; 34 Celsius-looking rows remain `UNVERIFIED_CELSIUS` with NULL canonical value. Do not treat as confirmed Celsius.
- **B10:** matching legacy defaults is insufficient proof of their provenance. Existing `backfillAssumedInputs.js` needs review and explicit authorization before updating historic flags; this batch only creates the third flag.
- **B17:** review ranges are audit triage heuristics, not clinical diagnosis; a qualified reviewer must assess flagged records. Report dates as privacy-shifted.
- Existing `observations_clean` view has a legacy fallback for rows without unit status, so treat pre-migration results with caution. After classification, unverified canonical Celsius should be NULL.
- The `--apply` action writes to the local test database. Never apply to shared/production DB without an approved rollout plan, evidence and recovery strategy.
