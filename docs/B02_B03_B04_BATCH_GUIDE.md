## B04 restore only when a disposable test DB exists

The bootstrap uses `schema-export.sql` from the root. Requires PostgreSQL 18+ server and `psql` client, Node backend dependencies installed, an existing **empty** database such as `parvah_audit_test`, and `DB_NAME=PRE_ER_TEST_DATABASE_NAME=parvah_audit_test`. It does not create databases or restore any patient records. Example in a trusted test environment:

```powershell
$env:B04_ALLOW_DISPOSABLE_BOOTSTRAP = 'YES'
# For a remote *disposable* test host ONLY:
# $env:B04_ALLOW_REMOTE_TEST_DB = 'YES'
cd backend
node ../scripts/b04-bootstrap-test-db.js --apply
```

**Never run this on Render's current Neon database, or any populated/shared database.** The script refuses populated databases and requires explicit opt-in. The dump was generated by PostgreSQL 18, so a PostgreSQL 17 server is not a supported restore target for this tool.
